整体架构总览

从上往下阅读：岗位负责业务决定，业务控制服务把关，LangGraph 组织执行。

01责任与入口

实名工厂岗位

项目负责人安排工作，工程师执行，独立审核人审查。总控可以由人担任，也可以委托 Agent 处理允许授权的工作。

企业工作台

受理项目、澄清需求、上传原件、分配模块、查看任务和提交业务决定。

↓提交业务请求与实名决定

02业务控制服务

统一校验身份、项目权限、任务合同、制品版本、门禁与风险，控制授权、状态迁移和工程发布。

人工批准先形成业务记录，再恢复流程。Agent 不能批准自身成果、扩大授权或完成风险豁免。

↓合同与授权有效，才允许执行

03流程编排与模块执行

LangGraph 主图与模块子图

管理任务推进、人工等待、工具循环和检查点恢复；执行前后重新检查授权与版本。

按已授权的模块合同安排执行。

工作模块与可选 Agent

模块定义工作范围、交付和审核要求。需要独立判断时加载 Agent；也可以由工程师完成。

按任务需要加载，不固定 Agent 数量。

↓按合同加载方法、调用获授权工具

04方法与工具

模块加载

Skill

描述工作步骤、依据、判断规则与停止条件。Skill 本身不授予权限。

LangGraph 工具循环

受控工具与 MCP

执行解析、计算、检索和格式校验。跨客户端复用的工具可通过 MCP 提供。

业务服务授予工具任务

独立厂商执行器

在已确认的 Windows／GX 环境中操作原生工程，保存对应版本与原始日志。

贯穿各层的数据与证据

PostgreSQL

保存业务记录、实名权限、审批和 LangGraph 检查点。

版本化制品存储

保存原件、候选、差异和验证日志，以版本与 SHA-256 绑定。

双层知识治理

个人参考与生产知识分别管理，引用时检查权限、适用范围及撤回状态。

五类业务模块

PLC／HMI 工程

程序、变量与 I/O、候选代码、点表、差异、回退和测试。

故障诊断与维护

故障假设、证据与反证、排查、维修和复验。

电气设计与改造

计算、选型、BOM、连接关系、图纸草稿和施工影响。

工艺与产能改善

FDC、TT／CT、瓶颈、动作优化、工艺窗口和改善验证。

能耗与运行优化

能耗基线、单位合格品能耗、待机损失及优化候选方案。

共用工程保障

工程审查与风险管理 · 真实工具验证 · 文档与工程交付 · 知识治理
